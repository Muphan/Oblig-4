Assignment 4 for the subject Programing 1 at Østfold Community College.

Oppgave 1: Just a basic class assignment, commented extra so it's easier to learn for other students.

Oppgave 2: We're tasked in making a blackjack game. I'm planning on giving it a roguelike spin.
- card_assets.py contains ascii elements for printing cards to the terminal
- ascii_renderer.py imports card_assets and draws the gamestate to terminal
- classes.py imports ascii_renderer, contains all game logic in classes
- Oppgave 2.py, imports the main class from classes and runs a loop that starts the game and lets user replay after game has ended.


GUI.py:
Started work on learning PyQt5 to give the game an UI
